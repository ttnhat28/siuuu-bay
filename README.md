# Siuuu Bay

Game một chạm kiểu Flappy Bird, chơi ngay trên trình duyệt (điện thoại hoặc máy tính), không cần cài đặt.

Số 7 pixel đánh đầu bay qua cột dọc, nhặt bóng để nạp chiêu xoay người SIUUU, nhận quà ngẫu nhiên mỗi 5 cột và đi qua các giải: Ngoại Hạng Anh → C2 → La Liga → C1 → Serie A → Saudi Pro League → World Cup.

## Cách chơi

| Thao tác | Tác dụng |
|---|---|
| Chạm / Space | Bật nhảy |
| Nút SIU / phím S | Xoay người SIUUU, bất tử một lúc (cần đầy thanh SIU) |
| P | Tạm dừng |

**Penalty và sút phạt:** thỉnh thoảng có cầu thủ lao vào xoạc, bạn được hưởng penalty hoặc sút phạt.
- Nhấn giữ thì thanh lực chạy lên xuống liên tục.
- Kéo để vẽ đường bay vào khung thành.
- Thả tay khi lực đang ở vùng xanh để sút.
- Ghi bàn được +10 (penalty) hoặc +15 (sút phạt), kèm 7 giây ăn mừng bất tử.

**Bị trừ điểm:**
- Bay vượt vạch việt vị màu vàng: −2 điểm.
- Va vào cầu thủ đối phương: −3 đến −10 điểm, tùy mức độ va chạm.

## Chạy thử

Mở file `index.html` bằng trình duyệt là chơi được. Muốn có link cho bạn bè thì bật GitHub Pages cho repo này: Settings → Pages → Deploy from branch → `main`, thư mục `/ (root)`.
